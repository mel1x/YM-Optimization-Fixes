# Optimization & Privacy

Аддон для PulseSync: снижает нагрузку на CPU/GPU и диск, устраняет утечки памяти и отключает сбор телеметрии в Яндекс Музыке.

## Что делает аддон

### Автоматические исправления (работают всегда)

- **Бесконечный замер FPS:** отключает постоянный цикл requestAnimationFrame анимации "Моей волны", который нагружает CPU и GPU даже при выключенной анимации (особенно на экранах с высокой частотой обновления).
- **Зависший шиммер картинок:** останавливает бесконечные фоновые анимации скелетона на уже загруженных из кеша обложках (убирает до 35-45% холостой нагрузки на ядро в длинных плейлистах).
- **Утечка SVG-иконок:** встраивает спрайт в страницу один раз вместо постоянной повторной загрузки внешнего SVG-файла движком Chromium.
- **Утечки памяти при навигации:** устраняет задержку старых страниц в RAM из-за замыканий в mobx-react-lite и предотвращает повторную инициализацию рекламного SDK.
- **Снижение износа диска:** прореживает запись очереди воспроизведения Ynison в localStorage. Реальные изменения (трек, пауза, очередь) пишутся сразу, а обычный сдвиг позиции - не чаще раза в минуту.

### Настройки

- **Блокировка трекинга:** режет запросы Яндекс Метрики, Webvisor, RUM, crash-репортов и рекламы. Телеметрия плеера прореживается до редких контрольных событий. Музыкальное API, авторизация и история прослушиваний работают без изменений.
- **Пульсация играющего трека:** отключает анимацию кружка на обложке текущего трека в списках.
- **Плавный прогресс-бар:** отключает субпиксельное движение полосы воспроизведения (время идет шагами в 1 секунду).
- **Hard Mode:** принудительно отключает все CSS/JS-анимации и размытия (blur/backdrop-filter), заменяя полупрозрачные панели на сплошные цвета темы.

## Проверка

Статистика работы аддона доступна в консоли DevTools (Ctrl + Shift + I):
```js
__perfTunerStats()
```
